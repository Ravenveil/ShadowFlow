## 如何提交材料（协作）

- **网页直接传（推荐，无需安装任何工具）**：在 GitHub 打开本文件夹下对应子文件夹 → **Add file → Upload files**，拖入作品提交（会自动生成 PR，审核后并入 main）。
- 没有仓库权限的伙伴：联系管理员在 Settings → Collaborators 邀请你，或把文件发给管理员代传。

## 注意

- 演示视频等大文件注意 GitHub 单文件 100MB 上限，超过请放网盘，并在对应文件夹里放下载链接。
- 本仓库是公开仓库，含个人信息、证件、资质的截图请先打码再上传。

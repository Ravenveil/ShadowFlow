v7 升级 · 删 persona · 加 statusline / diff / model-pill

Cherry Studio ★ NEW · model 标识

替换 coordinator.v1。assistant 身份不再是"虚构 persona"，看到的就是真在跑的模型 — 纯文字 brand 名 + mono · 分隔 + 版本号。Cherry Studio 自身在消息顶挂 Claude 3.5 Sonnet 那种 chip，我们吸语义但不吸图标/色块：让模型名以排版分量而非装饰获得权重，留下颜色预算给真正的语义信号（status dot、diff add/del）。

语义价值：多模型 IDE（用户可能在 Claude / GPT / DeepSeek 间切）下，这是唯一可信的身份标识；而 persona 名字（"coordinator.v1"）让人产生它有自我的错觉，反而干扰。

Codex CLI ★ NEW · persistent statusline

Codex 在 composer 下永远有一行 ✻ Composing for 14s · 3 shells running · ⌥+↵ newline · esc cancel — gerund verb（Composing / Validating / Diffing / Sautéed 这种创造性词）+ 耗时 + 并行 shell 数 + 键位提示。这是 Codex 跟传统 chat 视觉上最大的分水岭：永远在工作，永远在告诉你它在哪。

v7 实现：.statusline = mono 10px + accent ✻ 闪烁 + 三段 num 数据 + 右侧 kbd 群。每个 frame 底部都有它。

Claude Code ★ NEW · file:line + unified diff

(1) file:line dotted-underline ref — 不是裸文本路径，是 .fref：file 加粗 + 冒号 + 行号 accent + dotted underline，hover 整体高亮。出现在 tool args、tool echo、panel header 三处。

(2) 真 unified diff — B 方案 code panel 从 YAML 语法高亮升级到 + / - mark + gutter 行号 + 行级 add/del wash（color-mix(in oklch, var(--status-ok) 8%, transparent)）。@@ 头出现真实 hunk 坐标。

Codex compact mode turn separator

多轮跑久了 Codex 会把早期 turn 折叠成 ─── 4 turns compacted ─── 分隔条，两侧 hairline 拉满。A 方案演示该条 — 上一段 4 个 turn 被收掉，view summary 弹一个 hover panel。

这把"长 session 怎么不让左栏滚到爆"这个根本问题解了。配合 sf-text 协议里的 <sf:compact> 标签，可以在 model 主动 emit 时触发。

Codex & Claude Code ★ NEW · ✻ thinking node（pre-answer reasoning）

之前 v7 只在 assistant 末尾挂了一条 .tl-thought（Trae 风末尾反思）。Codex / Claude Code 实际的 reasoning 不在末尾 — 它在 user msg 与 answer 之间。Claude Code 会显示 ✻ Sautéed for 38s（gerund verb 由用户/模型挑）+ 耗时 + tokens，点开是多段斜体灰色推理；Codex 也是同样的位置 + 折叠形态。

v7 实现 .tl-thinking：折叠态一行 ☁ Thought for 38s · 1.2k tokens ›（mono 11px，accent 思考云 SVG 缓慢 pulse — 把 Codex / Claude Code 的 ✻ sparkle 换成填充式思考气泡 + 左下小尾巴（命名为「影流」），currentColor 继承），展开态是多段 italic var(--fg-4)，无 bg / 无 border / 无 shadow，只用 1.5px 左 rule 锚定到时间线，跟 .tl-thought 共享视觉语言但位置不同、语义不同。A 折叠 · B 展开，两态各演示一次。

语义价值：① 解释"模型为什么这么选"而不只展示结果（前文 0.65 的对比选项、边界检查都在 thought 里）；② 折叠态默认收起，不挤占主线；③ 用真实 tokens 数告诉用户"思考成本是多少" — 跟 msg-foot 的 cost 形成 thinking cost + output cost 双指标。

落地：新增 ThinkingBlock 组件（受控折叠态）+ <sf:thinking duration tokens> 标签 — 这是新增 sf-text 标签的第 3 个。

推荐 · 落地 接 v6 的推荐方向不变（方案 B + Shadow 三层），v7 在它之上钉死五个 token 级新规：(1) 每条 assistant turn meta 行首位是纯文字 model 标识（brand · ver），不是 persona 名、不是图标 chip；(2) 每个 RunSessionPage 底部钉一个 statusline，永远在跑，verb 随阶段轮换；(3) 所有 file path 渲染为 .fref，不写裸字符串；(4) 所有 edit/write tool 的结果用 .diff-block，不用 YAML 高亮；(5) 有 reasoning 的 turn 在 user msg 与 answer 之间渲染一个 .tl-thinking 折叠块，默认收起；末尾反思仍用 .tl-thought。

落地：S6.10（左栏 timeline）→ 加入 ModelPill、StatusLine、FRef、DiffBlock、ThinkingBlock 五个新组件；S6.11（sf-text 扩展）→ 新增 <sf:compact>、<sf:file-ref>、<sf:thinking> 三个标签（其它两个已在 v6 范围）。预计 +0.5 天，总 5.5 天。

v6 升级 · 四家 Agent IDE 的设计借鉴

OpenDesign ★ NEW · 自身已有

用户截图里的 ● Done 5m 40s · 26634 out · $1.3946 — 这是run-summary capsule，把整个 session 的总状态（status dot + duration + tokens + cost）收成一行 mono 行头，放在时间线最顶。一眼知道"花了多少 / 是否完成"。

同截图里 Editing ×3, Done 的折叠 chip — N 个同名连续 tool call 折叠成单行（diff 累加 + 状态点 + 展开 chev），点开变 ⎿ 续行串。v6 在 A 用折叠态、B 用展开态演示。

Shadow ★ NEW · ShadowclawResponseLayer

核心是结构化证据三层：主线结论（accent-tinted recess，accent/30 border + accent/10 bg，不加 shadow）+ 关键文件（chip row，文件图标 + name + role hint）+ 下一步（编号列表 + P0/P1 优先级 pill）。

每层用 UPPERCASE tracking-wider 10px opacity-60 sec-label 打头（取自 ShadowclawResponseLayer.tsx 的 text-xs font-medium uppercase tracking-wider opacity-60）。v6 全部 sec-label 沿用这套字体规格。

Codex CLI / Claude Code 字符前缀语义

❯ = user，● = assistant bullet，⎿ = tool 输出续行 — 把"谁在说话"和"工具回声"在零容器下分得很清。v6 保留 v5 决定。

额外：tool call 默认折叠（claude code 风格） + tool group 同名连续合并（OpenDesign 风格）。两者结合 = v6 默认简约态，展开按需。

Trae 任务 panel surface

任务面板 = 消息流里的 surface 内嵌块（暖灰底 + 顶部 mono UPPERCASE label「任务 · 0/3 已完成」），不是描边卡也不是独立侧栏。Thought 用斜体灰阶纯文本。

v6 方案 B 沿用：.fb .panel = bg-elev-1 + 8px 圆角 + 内 padding，无边框无 shadow。

推荐 · 下一步 推 方案 B + Shadow 三层吸入 assistant block 替换 v3 左栏：(1) run-cap 永远在顶；(2) assistant 主结论用 sec-label + reasoning recess 一次（每 turn ≤ 1）；(3) 角色/文件/触达资源用 chip row；(4) step / code 走 surface panel；(5) 连续同名 tool 自动合并成 tool-group。

落地：RunSessionPage.LeftPane 重构为 <ConversationTimeline>，item kind = run_cap · user_msg · assistant_block · tool_chip · tool_group · step_panel · code_panel · thought。assistant_block 内部支持 { reasoning, files, next_steps } 子段，对应 sf-text 协议里新增的 <sf:reasoning> / <sf:key-files> / <sf:next-steps> 三个标签（这部分需要扩 sf-text spec）。预计 S6.10（左栏 timeline）+ S6.11（sf-text 三标签扩展），4 天落地。

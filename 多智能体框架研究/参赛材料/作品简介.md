**项目名称**：ShadowFlow —— 软件研发全流程多 Agent 自主协同基座

**作品简介**：

软件研发中，缺陷与需求散落于 Issue、日志与群聊，任务拆解、指派、验证依赖人工，执行过程不可追溯，专家经验难以沉淀。ShadowFlow 面向企业研发团队的复杂任务协同场景，提供让多 Agent 协作从 Demo 走向 Production 的基础设施。

以 AgentTeams 为协同设计基点，核心方案包括：一、图式协作引擎——职能 Agent 经 DAG 互连（sequential / parallel / conditional 三类边），支持分层调度、层内并行扇出、条件路由与失败级联，自动完成任务拆解与分工；二、结构化上下文传递——节点间以产物文件与标准化结果显式交接，step / trace 原子落盘，证据可回放、可审计；三、Skill 工程化体系——技能以"说明文档 + 机器可读清单"双格式封装，支持导入、版本管理与复用；四、安全边界——策略门对协作边做放行 / 警告 / 拦截三态过滤，高风险动作经人工审批门确认，支持重试与回滚。演示闭环：Planner 拆解 → Coder 编码 → Reviewer 挑错 → Verifier 验证复盘，四职能 Agent 端到端完成研发任务协同。

差异化优势：协作画布与执行引擎一体，拓扑可视化编排、运行状态实时投影；群聊一句话即可驱动 DAG 执行；执行证据天然沉淀为可回放时间线，全程可查可审计。

开放与复用：Agent 定义、Skill 包、协作模板均可导出分享，计划开源协作引擎与核心 Skill 清单，并提供 MCP 等价集成契约。

当前进展：双引擎已在产品中真实运行，支撑多 Agent 群聊协作与执行会话；具备步骤级重试恢复、时间线回放与产物预览；三栏工作台前端已上线。

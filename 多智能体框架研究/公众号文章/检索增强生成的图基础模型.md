# 文献精读 | 用于检索增强生成的图基础模型 (NeurIPS 2025)

> **Title**: GFM-RAG: Graph Foundation Model for Retrieval Augmented Generation
> 
> **Conference/Journal**: NeurIPS 2025
> 
> **Link**: https://arxiv.org/pdf/2502.01113

这篇论文提出了一种名为 GFM-RAG 的新型图基础模型，它通过构建知识图谱并利用查询依赖型图神经网络，在单步内高效地进行多跳推理，从而显著提升了检索增强生成（RAG）在复杂问答任务中的性能、效率和泛化能力。

## 研究背景与动机

大型语言模型（LLM）在知识获取和复杂推理方面存在局限。传统的检索增强生成（RAG）方法难以捕捉知识间的复杂关联，而现有图增强 RAG（GraphRAG）又受限于图结构噪声、不完整性及泛化能力差。因此，本研究旨在开发一种能够在大规模数据集上训练并有效泛化到新场景的图基础模型（GFM），以增强 LLM 的多跳推理能力，从而实现更高效、准确的知识检索与生成。

## 核心方法

GFM-RAG 构建了一个两阶段训练的图基础模型（GFM）检索器，该检索器基于查询依赖型图神经网络（query-dependent GNN），通过从文档中构建知识图谱索引（KG-Index）来显式建模知识间的复杂关系，从而在统一的语义和图结构空间中实现单步高效的多跳检索，最终将检索到的相关文档输入大型语言模型（LLM）进行答案生成。

### 知识图谱索引构建

首先从文档中提取实体  和关系  以形成三元组 ，然后使用 LLM 作为开放信息抽取 (OpenIE) 工具，构建实体到文档的倒排索引 。为了更好地捕捉知识之间的联系，进一步进行了实体消歧，使用预训练的密集嵌入模型在语义相似的实体之间添加额外的边 ，最终的 KG-index G 被构建为 。

### 图基础模型检索器

GFM 检索器采用查询依赖型 GNN 来识别图谱中相关的实体，这将有助于定位相关文档。

#### 查询依赖型 GNN

查询依赖型 GNN 在理论上被证明具有多跳逻辑推理能力，它被选为 GFM 检索器的骨干，允许 GFM 检索器根据用户查询动态调整消息传递过程，并通过多跳推理在图上找到最相关的信息。

在查询  条件下，给定知识图谱  和初始实体特征  ，经过  层消息传递后得到更新的实体表示 。

**查询依赖性消息传递**

将信息从问题实体传播到 KG 中的其他实体，以捕捉它们与查询的相关性。

在**三元组级别**上，通过和查询相同的句子嵌入模型（查询、实体、关系都使用相同的句子嵌入模型）获得关系  的初始嵌入  ，消息生成函数  在 KG 中的所有三元组上操作以生成消息，它结合了源实体e 的表示 、关系 r 的更新表示  （这是一个层特定函数，用由两层 MLP 实现）和目标实体 e′ 的表示  来生成消息 。

在**实体级别**上，实体 e 的表示  的更新结合了实体 e 当前的表示  和来自其邻居  的聚合消息 。对于每个实体，我们使用求和聚合来自其邻居  的消息，并使用单个线性层更新实体表示。

经过 L 层消息传递后，一个最终的 MLP 层连同 sigmoid 函数将实体嵌入映射到它们与查询的相关性分数。

#### 训练过程

GFM 检索器采用两阶段训练策略，两个阶段共享同一个由三个目标函数组合而成的损失函数。

**二元交叉熵损失（）**：将每个实体视为独立的二分类问题。 表示与查询  相关的正例实体集合（即目标实体）， 表示负例实体集合。第一项最大化正例实体的预测相关性分数 （趋近 1），第二项最小化负例实体的预测分数（趋近 0）。该损失确保模型能独立判断每个实体是否与查询相关，相当于一个标准化的二元交叉熵。

**排序损失（）**：直接优化正例实体在排序中的位置。对每个正例实体 ，计算其分数  占所有负例实体分数之和的比重，负号使其成为最小化问题。该损失鼓励模型将正例实体排在所有负例实体之前，本质上是 softmax 排序损失的一种变体，专注于检索场景下的排序质量。

**组合损失（）**：通过超参数  平衡 BCE 损失和排序损失的权重。BCE 损失提供独立的实体相关性判断能力，排序损失则聚焦于正例相对负例的排序位置。两者互补：前者保证"判断准不准"，后者保证"排得好不好"。实验中 ，即赋予排序损失 0.7 的权重，反映出检索任务的核心目标——将相关实体排在前面。

**自监督 KG 补全预训练**

为了增强 GFM 检索器的图推理能力，首先在大规模知识图谱补全任务上进行自监督预训练。具体而言，从 KG-index 中采样一批三元组，遮蔽其中头实体或尾实体，构造合成查询  或 ，被遮蔽的实体即为目标实体  或 。GFM 检索器以方程(13)的损失函数为目标，学习在查询和知识图谱条件下预测被遮蔽的实体。这种预训练方式使模型在无需人工标注的情况下学习到图谱中丰富的结构模式和关系推理能力，为后续泛化到未见过数据集奠定基础。

**监督文档检索微调**

在自监督预训练之后，使用标注文档对 GFM 检索器进行有监督微调。在此任务中，查询  是自然语言问题，目标实体  从标注的支撑文档  中提取而来。GFM 检索器使用与方程(13)相同的训练目标，学习从 KG-index 中检索与给定查询最相关的实体。这一步骤将预训练阶段习得的通用图推理能力适配到具体的文档检索场景，使模型能够将检索到的相关实体映射到包含这些知识的文档上。

## 实验与结果

### 实验设置

**数据集**：（1）三个多跳 QA 基准：HotpotQA、MuSiQue、2WikiMultiHopQA（2Wiki）；（2）七个跨领域 RAG 数据集，涵盖生物医学（PubMedQA）、客服（TechQA、DellQA）和通用知识（MS MARCO、Hagrid）。

**基线方法**：单步朴素方法（BM25、ColBERTv2、RAPTOR 等）、图增强方法（GraphRAG、HippoRAG、SubgraphRAG、G-retriever）、多步方法（Adaptive-RAG、FLARE 及 IRCoT 框架）。

**评估指标**：检索用 Recall@2/Recall@5，问答用 EM/F1。

**实现细节**：6 层查询依赖消息传递，隐藏维度 512；all-mpnet-base-v2 嵌入（冻结）；8M 参数；8×A100（80G）训练，batch size 4，学习率 5e-4，。

### 效率分析

![image](https://mmbiz.qpic.cn/sz_mmbiz_png/YlXlFRicyrR1bWJpia8UxzP89SBIgjtY4P3vQ0477C59ndnefdIMx4mvkGEOYbDED06pyyOOSmRfCibrdsl2U9KphjSRDF9EL9wicqClHfozcqc/640?wx_fmt=png&from=appmsg&tp=wxpic&wxfrom=5&wx_lazy=1#imgIndex=4)

尽管 GFM-RAG 的 GNN 推理步骤耗时高于朴素单步方法（ColBERTv2、HippoRAG），但它在不依赖 LLM 迭代的情况下即达到了最高的 R@5，效率远超需要多轮 LLM 调用的 IRCoT 系列方法。多步的 IRCoT + GFM-RAG 在耗时上（约 0.1s）反而远低于仅靠 LLM 迭代的多步基线，说明将多跳推理从 LLM 迭代转移到单步 GNN 推理，是兼顾有效性与效率的合理设计。

### 消融研究

作者对多个组件进行了消融分析：（1）不同句子嵌入模型的影响——GFM-RAG 对不同句子嵌入模型不敏感，表明模型的鲁棒性；（2）预训练策略——自监督 KG 补全预训练对最终性能至关重要；（3）损失权重策略——BCE 与 ranking loss 的组合权重  对性能敏感， 为最优；（4）排序方法——逆频率加权策略优于朴素求和；（5）训练数据——更多训练数据带来更好的性能；（6）KG-index 构建——实体消歧（添加  边）对性能有显著提升。

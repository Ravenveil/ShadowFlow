# 知识库统一重构 — 单一知识源列表 + NeoApp 项目联动 + 图谱/处理入口

## 概念模型

**知识源 = 本地文件夹(含当前项目文件夹)+ 知识包(RAG 索引单元)**。知识页三件事:看源(浏览/阅读)、处理源(建包/重索引)、看图谱。

## 整体布局

左栏固定 ~260px 知识源列表;右侧内容区自动占满剩余宽度,内容随左栏选中项变化,共三种状态:

**① 选中文件夹源 → 仓库浏览器**(现有 VaultBrowser 原样搬入,去掉「返回」键)
- 顶行:仓库名 + 路径 + 文件总数 + 刷新
- 左半:文件树(目录折叠 + 过滤框);右半:阅读器(md 用 NeoMarkdown 渲染、图片/PDF 直链预览、文件路径+大小+「在系统中打开」)

**② 选中知识包 → 包详情**(现 PackCard 展开态改造为详情页)
- 标题行:包名 + 状态徽章 + [知识图谱] [Reindex] [Delete]
- 描述/时间、retrieval 配置、sources 明细(类型+引用+ingest 状态+chunk 数)

**③ 未选中/空 → 概览页**
- 当前项目卡(若有)、两类源计数、RAG 后端徽章;空态两张引导卡(打开本地文件夹/新建知识包)

## 左栏:扁平知识源列表(Shadow KbRail / ima 模式)

```
│ 知识库          [+ 添加 ▾] │  ← 栏头:标题+添加菜单(无独立页头)
│  📁 MyProject [项目] 290篇 │  ← 当前项目文件夹自动置顶带徽章
│  📁 docs                  │
│  🗃 pack1        ready     │
│ [ + 打开本地文件夹 ](虚线)  │  ← 最高频动作直达
```

- 不分组:📁=文件夹、🗃=知识包,图标区分;元信息(文件数/状态点);按最近使用排序
- Memory 统计条删除(归 /memory 页);嵌入 NeoApp 中栏时左栏 200px;单击即切换右侧,自动选中第一项

## NeoApp 联动(两件事)

1. **项目选择 → 知识库自动出现该源**:知识页读 NeoHost 同一存储键(sf.project-folder),自动注册置顶+「项目」徽章;换项目刷新即同步
2. **NeoRail 左栏 → 定位到源**:NeoRail 知识库区改列全部源;点某行 → 中栏知识页打开并已选中该源(NeoNav 加 sourceId;/knowledge 路由支持 ?source=)

## 「+ 添加 ▾」菜单(Shadow 三动作)+ 处理/图谱

- **打开本地文件夹**:原生选夹器一步注册选中(零中间弹窗);503 回退粘贴路径弹窗
- **新建本地仓库**:输名称→选父目录→后端建目录+注册
- **新建知识包**:现有 CreatePackModal
- **知识处理**:包详情保留 Reindex/Delete;文件夹源加「从此文件夹建知识包」(预填路径,打通 vault→pack)
- **知识图谱**:包详情按钮 → 现有 /knowledge/graph?pack=…

## 如何提交材料（协作）

- **网页直接传（推荐，无需安装任何工具）**：切换到 `deliverables` 分支 → 打开对应文件夹 → **Add file → Upload files**，把作品拖进去提交即可。
- 也可以用 git 把文件推到 `deliverables` 分支，不影响 main。
- 没有仓库权限的伙伴：联系管理员在 Settings → Collaborators 邀请你（接受后即可按上面方式上传），或把文件发给管理员代传。

## 注意

- 演示视频等大文件注意 GitHub 单文件 100MB 上限，超过请放网盘，并在对应文件夹里放下载链接。
- 本仓库是公开仓库，含个人信息、证件、资质的截图请先打码再上传。

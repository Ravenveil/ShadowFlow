## 侧边栏结构（从截图提炼）

```
┌─────────────────────────┐
│ [窗口控件]  [布局] [搜索] [+]  ← 顶部：布局切换/搜索/新建
│                         │
│      (Grok 头像)         │ ← 主 Bot 大头像居中，带在线状态点(橙色)
│      Grok Bot            │
│                         │
│ 工作                     │ ← 自定义分组标题（灰色小字）
│ 🟠 自媒体管家             │ ← 会话项：圆角方头像 + 名称
│    彩标，已经停了…        │    + 最后一条消息预览（灰色截断）
│ ⬛ 资讯助手              │
│    搭好了，明早第一期…    │
│ 生活                     │ ← 第二个分组
│ 👧 生活管家              │
│    日历里只有这周五…      │
│ Work                 >  │ ← 折叠的空分组（可展开）
│ Invest              3   │ ← 未读计数
│ Life                6   │
│                         │
│ (底部输入提示区)          │
└─────────────────────────┘
```

## 关键设计要点

1. **会话即 Bot**：侧边栏没有单独的"员工/团队"页面——每个 Bot 就是一个会话项
   （头像 + 名称 + 最后消息预览），点进去直接聊天。团队/派活体现在聊天流里。
2. **分组是用户自定义的**：中文标题（工作/生活）+ 英文标题（Work/Invest/Life）混用，
   空分组显示 chevron，有未读的显示计数徽标。
3. **头像**：圆形，每个 Bot 一个独特图案（emoji 风格/插画风格），主 Bot 在侧边栏顶部
   居中放大显示，右下角带状态小圆点。头像可更换（09:21 头像分组章节）。
4. **派活交互（10:40 主Bot派活 / 11:17 记忆交接）**：在聊天流里完成——
   主 Bot 回复"好，我把这件事转给生活管家…"，上方出现系统提示条
   "已发消息给 👧生活管家"，带目标 Bot 的小头像。@某 Bot 即转交。
5. **定时任务（11:55）**：Bot 对话内配置，执行结果以"记好了：10月30号…已经 mentions
   全家日程…提前 1 小时提醒你"这类卡片回传到会话流。
6. **群聊形态**：多个 Bot 协作时，聊天流里的每条消息带各自 Bot 头像（类似群聊），
   转交/汇报都有系统提示条分隔。
7. **整体风格**：浅色主题、大圆角（会话项/卡片 ~12px）、灰阶分隔、极简无边框输入框、
   侧边栏宽约 280-300px、会话项选中态为浅灰背景。

## 对应到 ShadowFlow 的改造映射

| Grok Bot 概念 | ShadowFlow 现状 | 改造方向 |
| --- | --- | --- |
| Bot 会话项 | agent（无独立会话） | 每个 agent 一条会话项，头像用 dicebear 生成 |
| 自定义分组（工作/生活） | 团队（team） | 团队作为侧边栏分组标题，组内是 agent 会话项 |
| 主 Bot 派活（@转交） | orchestrator 派发事件 | agent.message 事件渲染为群聊气泡 + 转交系统条 |
| 头像更换 | 无 | agent 卡片弹窗：dicebear 换 style/seed 或上传图 |
| 定时任务 | 无（后端缺口） | 新增 scheduler 模块 + 会话内配置 UI |
| 未读计数/折叠分组 | 无 | 团队折叠 + 未读徽标 |
